# Pushkar Kumar Personal Website

Static personal portfolio site generated from the resume at `assets/Pushkar_Kumar_Resume.pdf`.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. In the repository settings, open **Pages**.
4. Set **Source** to **GitHub Actions**.
5. Push to the `main` branch. The included workflow deploys the site.

For a user site at `https://0xpushkar.github.io`, name the repository `0xpushkar.github.io`.

## Update

- Edit `index.html` for content changes.
- Edit `styles.css` for visual styling.
- Replace `assets/Pushkar_Kumar_Resume.pdf` when the resume changes.
